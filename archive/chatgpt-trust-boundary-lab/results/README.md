# Scripted fixture output

`scenario_results.csv`, `summary.json`, and `scripted_fixture_metrics.svg` are reproducible outputs of `trust-boundary-evaluate --output results` over the checked-in eight constructed scenarios. They describe deterministic policy behavior on those fixtures only. They are not model benchmark performance, real-world attack rates, human-study data, or statistically significant results. For per-scenario review, inspect the CSV; summary metrics include the fixture count in `summary.json`.
