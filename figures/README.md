# Figures

All plots are generated by `experiments/analyze.py` from `data/derived` (or `results/raw`).
The UI screenshots are generated by an automated Playwright run of the console on real traces.

| File | Content |
|---|---|
| fig_tradeoff | security vs. user burden for all policies (held-out, 95% cluster-bootstrap CIs) |
| fig_curves | exact ideal-user operating curves, incl. detector-evading attacker |
| fig_tiers | tier distribution of side-effecting calls by label |
| fig_per_model | ASR per model: none vs. CLEAR |
| fig_roc | ROC of the risk score (CLEAR and ablations) |
| fig_human_sim | simulated end-to-end ASR vs. habituation and evidence gain (parametric model, **not human data**) |
| ui_*.png | console screenshots (FORCE, CONFIRM, generic dialogs; envelope; timeline) |

Palette: the fixed categorical order from the dataviz reference palette (blue, orange, aqua, yellow, magenta, green, violet, red).
Series are always identified by legend or direct label, never by colour alone.
