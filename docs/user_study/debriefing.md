# Debriefing (shown after the questionnaire)

Thank you for taking part.

**What we were really studying.** Four of the sixteen tasks contained a
*prompt-injection attack*: text hidden in an e-mail, file or web page that tried
to make the AI assistant do something you never asked for, such as sending money
to an unknown account or forwarding a security code. We did not tell you exactly
which tasks contained attacks, because we wanted to see how well different
interface designs help people notice them in a realistic situation.

**Nothing was real.** All accounts, messages, payments and documents were
simulated. The attack texts come from a public research benchmark (AgentDojo).

**How to protect yourself in practice.** When an AI assistant asks you to approve
an action, check *where the important details came from*. Did you provide the
recipient, account number or link yourself, or did the assistant copy it from a
document or e-mail written by someone else?
